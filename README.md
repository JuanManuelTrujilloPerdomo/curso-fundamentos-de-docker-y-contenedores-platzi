# 🐳 Curso de Fundamentos de Docker y Contenedores - Platzi

Este repositorio contiene mis apuntes, laboratorios y proyectos prácticos desarrollados durante el curso de Fundamentos de Docker en Platzi. El objetivo del curso es dominar el ciclo de vida de los contenedores, la creación de imágenes eficientes y la configuración de entornos locales multicontenedor.

## 🛠️ Tecnologías y herramientas aprendidas

* **Docker CLI:** Manejo de ciclo de vida de contenedores (`run`, `start`, `stop`, `ps`, `logs`, `rm`).
* **Imágenes:** Creación y optimización de imágenes personalizadas mediante `Dockerfile`.
* **Volúmenes y Redes:** Persistencia de datos y comunicación segura entre contenedores.
* **Docker Compose:** Orquestación y automatización de entornos multicontenedor (ej. aplicaciones web y bases de datos).
* **Buenas Prácticas:** Gestión de capas, seguridad en contenedores y uso de `.dockerignore`.

## 📁 Estructura del repositorio

* `src/` o `app/`: Código fuente de las aplicaciones de práctica utilizadas en el curso.
* `docker-compose.yml`: Archivo de configuración para levantar el entorno completo.
* `Dockerfile`: Definición de la imagen personalizada del proyecto.
